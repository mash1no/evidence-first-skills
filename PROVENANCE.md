# Provenance and scope

This public package is a new, generic implementation commissioned for public distribution. It is not a byte-for-byte mirror, code extraction, or complete replacement of earlier private skills named `evidence-first` or `industrial-evidence-first`.

The earlier private materials did not establish a complete authorship and license chain. This publication makes no claim that those earlier materials are wholly original or publicly licensed. Their implementation files, project-specific instructions, data, training examples, frozen verifiers, schemas and execution records are excluded.

The public instructions, two independent validators and synthetic tests were newly written for this package from general evidence-management requirements. The validators use only Python's standard library; no third-party implementation is vendored. They neither import nor require a private project.

The examples use invented identifiers, values and text. They must not be used as actual measurements, product specifications, supplier facts, inventory records or proof of a successful deployment.

The public tools implement a deliberately smaller scope: local text-reference consistency and explicit quantity/source checks. They do not reproduce private training, CAD parsing, dispatch, runtime supervision or model-evaluation pipelines.
